# Матклуб — by ddima_dev

## Курс C++17

Информатика открыта без пометки «Альфа»: Python и C++ доступны в соседних вкладках. C++ содержит 20 уроков, 2 итоговых проекта, 22 задания с решениями и 22 вопроса с проверкой и объяснением. Темы: типы, ввод, ветвления, циклы, строки, vector, функции, ссылки/const, структуры, классы, map, STL, бинарный поиск, рекурсия, исключения, потоки, RAII/unique_ptr, шаблоны и тестирование.

Редактор сохраняет черновики и самостоятельные отметки прохождения в `matclub-cpp-v1`. Можно скачать `main.cpp`; компиляция пользовательского кода в браузере не выполняется. В каждом уроке приведены команды для GCC/Clang и MSVC, входные данные и ожидаемые результаты. Примеры и эталонные решения проверяются локальным компилятором C++17, а вопросы на понимание проверяются прямо на сайте. Отметка прохождения не означает автоматическую проверку программы.

Проверки: `python3 scripts/check-cpp.py` (требуется g++, 77 запусков примеров и решений с `-Wall -Wextra -Wpedantic -Werror`) и `node scripts/check-cpp-ui.cjs` (требуется jsdom). Генератор `node scripts/build-search.cjs` создаёт `/cpp/` и 22 текстовые страницы; карта сайта содержит 172 URL. Ссылка `/?cpp=hello` открывает курс. Визуальная проверка в настоящем браузере в текущей среде недоступна.

## Физическая лаборатория

Отдельный раздел навигации «Лаборатория» (на телефонах — «Опыты»), без пометки альфа/бета. 20 готовых опытов: бросок под углом, наклонная плоскость, столкновение тел, маятник, пружина, Архимедова сила, гидростатика, идеальный газ, нагрев, смешивание, закон Ома, соединения резисторов, RC-цепь, индукция, бегущая и стоячая волны, преломление, линза, фотоэффект и распад.

Каждый опыт содержит управляемую SVG-установку, показания, график с закреплением предыдущих условий, формулы, границы применимости, план исследования и расчётную задачу с проверкой ответа. Динамические опыты запускаются только по команде пользователя; доступны пауза, шаг, шкала времени и скорость. Один проход шкалы занимает около 12 секунд при 1× независимо от физической длительности, которая всегда указана отдельно. При уходе из раздела или скрытии вкладки воспроизведение останавливается.

Параметры, гипотеза, вывод и до 120 измерений на каждый опыт сохраняются в localStorage (`matclub-laboratory-v1`). CSV содержит параметры, показания и заметки; график экспортируется в SVG. Запуск моделей не требует внешнего API, интерпретатора или библиотеки графиков. Все вычисления детерминированы; распад показывает математическое ожидание, а не случайные события.

Исходники: `dist/lab-models.js` (чистые расчёты и материалы), `lab-scenes.js` (установки), `lab.js` (интерфейс и журнал), `lab.css`. Ссылки `/?lab=projectile` и `/?lab=lens` открывают соответствующий опыт. Генератор `node scripts/build-search.cjs` создаёт также каталог `/laboratory/` и 20 справочных страниц; карта сайта теперь содержит 149 URL.

Проверки: `node scripts/check-laboratory.cjs` — физические инварианты, размерности, границы, производные и диапазоны параметров. `node scripts/check-laboratory-ui.cjs` — интеграционные проверки в JSDOM (нужен пакет `jsdom`, можно использовать `NODE_PATH` существующей QA-установки). Проверены все 20 интерфейсов, пресеты, измерения, фильтры, сохранение, экспорты и глубокие ссылки. Визуальный браузерный прогон в среде разработки недоступен; JSDOM не проверяет фактическую раскладку и отрисовку.

Независимый статический сайт: математика 6–11 классов и физика 7–11 классов.
Содержимое `dist/` работает без ChatGPT, серверного приложения и внешних API.

## Бесплатная публикация на GitHub Pages

1. Создай публичный репозиторий `matclub` в своём аккаунте GitHub.
2. Загрузи содержимое этой папки в ветку `main`, сохраняя структуру каталогов.
   Не забудь скрытую папку `.github` с файлом `workflows/pages.yml`.
3. В репозитории открой Settings → Pages → Source → GitHub Actions.
4. Открой Actions → Publish Matclub → Run workflow (или сделай новый коммит).
5. После успешного выполнения ссылка появится в Settings → Pages.
   Обычно это https://ИМЯ-АККАУНТА.github.io/matclub/ .

Для загрузки через Git:

```sh
git init -b main
git add .
git commit -m "Publish Matclub"
git remote add origin https://github.com/ИМЯ-АККАУНТА/matclub.git
git push -u origin main
```

Редактируй HTML, JS и CSS в `dist/`. После изменения CSS-исходников запусти
`python3 scripts/bundle-css.py`. В браузер загружается собранный `app.css`.
Для локального просмотра: `python3 -m http.server 8000 --directory dist`.

Учётных записей и синхронизации между устройствами нет.

## Поисковая индексация

Основной адрес: https://matclub1.dimakanonik317.workers.dev/ .
После изменения уроков запускай `node scripts/build-search.cjs` и публикуй
обновлённую папку dist целиком. Генератор создаёт 97 статических страниц уроков,
каталог /topics/, robots.txt и sitemap.xml.

Для другого адреса передай SITE_URL генератору и обнови canonical и og:url
в dist/index.html. Не поддерживай несколько разных основных адресов одновременно.

В Google Search Console добавь ресурс с префиксом URL основного адреса,
подтверди владение HTML-файлом или метатегом. В Яндекс Вебмастере добавь тот же
адрес и подтверди владение. Затем отправь /sitemap.xml в обоих сервисах.
Файл или метатег подтверждения выдаёт сам поисковик после входа владельца.
Код подтверждения нельзя выдумывать. Добавление карты не гарантирует индексацию
или конкретную позицию в поиске.

## Python: от первой строки к своим проектам

`dist/python-data.js` содержит 24 полноценных урока в шести ступенях и четыре итоговых проекта. Всего 52 задания с шаблонами, подсказками, эталонным кодом и 121 автоматической проверкой. Уроки покрывают основы, коллекции, функции, файлы/JSON, ООП, dataclass/аннотации, генераторы, алгоритмы, unittest, декораторы, контекстные менеджеры, asyncio, контракты API, Decimal и выпуск небольшого проекта. Все темы доступны сразу; это отдельный курс, который не меняет 648 школьных задач.

Редактор в `dist/python.js` запускает настоящий Python 3.12.7 через Pyodide 0.27.7 в отдельном Web Worker. При первом запуске файлы интерпретатора загружаются с закреплённого адреса `https://cdn.jsdelivr.net/pyodide/v0.27.7/full/`; чтение уроков не запускает эту загрузку. Для холодного запуска нужен доступ к CDN. Команда «Остановить» завершает worker; лимит выполнения — 10 секунд, загрузки — 60 секунд. Вывод ограничен, а временный каталог и пространство имён создаются отдельно для каждого теста. Файлы упражнений не сохраняются между запусками; черновики и прогресс хранятся в localStorage этого браузера. Учётная запись не нужна.

Проверки: `node scripts/check-python.cjs` (нужен Python 3.11+ для выполнения примеров с верхнеуровневым await). Проверяются все примеры, синтаксис шаблонов, эталонные решения и отказ от пустой реализации. После изменения материалов запускай `node scripts/build-search.cjs`: он дополнительно создаёт `/python/`, 28 текстовых страниц уроков/проектов и карту сайта из 128 URL. Ссылки `/?python=hello` и `/?python=project-todo` открывают нужную тему прямо в редакторе.
